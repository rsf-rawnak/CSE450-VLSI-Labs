# CSE 450 — VLSI Design Labs

A collection of digital logic design and VLSI laboratory experiments completed as part of the **CSE 450: VLSI Design** coursework at the **University of Asia Pacific (UAP)**.

This repository contains lab projects, circuit designs, and supporting reports covering fundamental logic gates through larger digital systems, including adders, a register, an arithmetic logic unit (ALU), and CPU design.

## Topics Covered

- Fundamental digital logic gates: NAND, NOR, OR, XOR, and XNOR
- Combinational logic design
- Full-adder circuit design

- Register design
- Arithmetic and logic operations using an ALU
- CPU design fundamentals
- Circuit implementation, simulation, and verification

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rsf-rawnak/CSE450-VLSI-Labs.git
```

Navigate to the project directory:

```bash
cd CSE450-VLSI-Labs
```

Browse the experiment folders and open the PDF reports for additional documentation. Reproducing the designs may require the relevant EDA software, project files, libraries, and simulation configuration.
